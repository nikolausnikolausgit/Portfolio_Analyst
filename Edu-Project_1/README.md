# Программа для получения данных об абитуриентах

### Цель:
* Создать программу (консольную), в какой можно было бы делать запросы к базе данных абитуриентов. 

### Ход работы:
* Поиск базы данных в интернете, её импорт из Excel в Spyder (IDE для Python)
* Подготовка отчетов в виде списков, графиков и сводных таблиц: предобработка данных, создание функций и пользовательского интерфейса
